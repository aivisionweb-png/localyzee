# LOCALYZE FINAL

Premium local-business SaaS demo.

## Routes
- `/` landing + pricing
- `/dashboard` owner console
- `/business/shreeji-cafe` customer website

## Included
- Premium ivory / navy / champagne-gold visual system
- Add Business modal
- Multiple business profiles stored in browser localStorage
- Customer site generated from business slug
- Dashboard metrics, activity, offers and billing
- UPI QR + UPI intent targeting `kaustubhbhudev@fam`

## Deployment
Upload the contents of this folder to the root of a fresh GitHub repository, then import that repository into Vercel.

## Real payments
The UPI flow is intentionally a demo. A production recurring SaaS needs a merchant payment gateway, server-side payment verification, webhook handling, authentication, database and subscription management. Do not claim a subscription is paid based only on a client-side UPI QR.
